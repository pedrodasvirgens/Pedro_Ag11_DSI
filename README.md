# Controle de Níveis de Água

## Sobre o projeto

O **Controle de Níveis de Água** é um programa desenvolvido em Python para auxiliar no desenvolvimento de um sistema simples de monitoramento de um reservatório de água. Os níveis serão representados em uma lista, do mínimo ao máximo, possuindo uma mensagem de alerta e a uma cor.

## Objetivo

O objetivo do projeto é utilizar estruturas de lista, biblioteca colorama, exibição e simulação no Python para desenvolver um sistema simples monitoramento de um reservatório de água.

## Como executar

1. Tenha o Python instalado em seu computador.

2. Abra a pasta do projeto no Visual Studio Code ou em outro editor.

3. Abra o arquivo Python do projeto.

4. Instale a biblioteca colorama pelo terminal com:

`python -m pip install colorama`

5. Execute o programa pelo terminal utilizando o nome do arquivo:

`python app.py`


O programa apresentará os cinco níveis de água do reservatório, cada um associado a uma mensagem de alerta e a uma cor específica: vermelho para o nível 1, amarelo para o nível 2, verde para o nível 3, ciano para o nível 4 e azul para o nível 5.

## Testes realizados

Antes da execução definitiva, o programa foi testado para verificar o funcionamento da lista de níveis, da função responsável por definir as cores e da exibição das mensagens no terminal.

Durante os testes, foram verificadas as correspondências entre os cinco níveis do reservatório e suas respectivas cores, além da restauração do estilo padrão do terminal após a exibição das mensagens.
